# Что нужно от тебя для деплоя в интернет

Я могу подготовить код, закоммитить, поставить CLI и задеплоить.
Полностью без тебя нельзя: аккаунты и логин — только у тебя.

## Сделай это один раз (5–10 минут)

### 1. GitHub
1. Зарегистрируйся на https://github.com (если ещё нет).
2. Напиши мне: «готово, есть GitHub» — я создам репозиторий и запушу код
   (через `gh` после твоего логина в браузере).

### 2. Railway (API + база)
1. https://railway.app → Sign up через GitHub (бесплатный пробный план).
2. Напиши: «Railway готов» — я задеплою `server/` и подключу Postgres.

### 3. Vercel (сайт)
1. https://vercel.com → Sign up через GitHub.
2. Напишу: «Vercel готов» — я задеплою фронт и пропишу `VITE_API_URL`.

### 4. Домен (по желанию)
- Без домена сразу будет адрес вида `https://….vercel.app`.
- Свой домен: купи на REG.RU / Namecheap / Cloudflare и пришли название —
  подскажу DNS (или настрою в Vercel, если дашь доступ).
